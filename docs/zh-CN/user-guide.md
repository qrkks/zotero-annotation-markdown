# 使用指南

[English](../en/user-guide.md)

## 支持的行为

- PDF 和 EPUB 阅读器侧栏里的标注评论默认按 Markdown 渲染。
- LaTeX 数学公式默认启用，支持 `$...$`、`$$...$$`、`\(...\)` 和 `\[...\]` 分隔符。
- 单个换行会保留为可见换行。
- 裸 URL 会在渲染预览中自动变成可点击链接。
- 使用 `==双等号==` 包裹的文字会渲染为高亮；可通过颜色后缀选择安全的预设颜色。
- 编辑时在快速编辑器中显示原始 Markdown 源码，失焦或按 Esc 即保存。
- 不信任原始 HTML，渲染结果会经过清理。
- Markdown 渲染失败时保留原始纯文本。

### 图片链接

一个段落只有 Markdown 链接、引用式链接或裸 URL 时，如果其 HTTP(S) 路径以 `.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.avif` 或 `.bmp` 结尾，就会显示图片预览。`images.openai.com/static-rsc/` 及 `/static-rsc-4/` 等带版本路径下的 HTTPS 链接即使没有文件扩展名，也会识别为图片。句子中的链接、标题、紧凑列表项、代码示例及其他网页链接保留原有排版。

图片采用懒加载并适配标注预览宽度，图片下方保留原始链接及标题格式；点击图片或标题会沿用现有链接处理逻辑打开原始地址。加载失败时仅保留标题链接。侧栏和页内弹窗的 Markdown 预览均适用，存储的 Markdown 原文保持不变。显式的 `![描述](https://example.org/photo.jpg)` 图片沿用现有行为。

图片预览接近视口时才获取数据，并仅保留在有限的内存缓存中；重复链接复用数据，不创建附件。响应须为支持的位图格式，大小不超过 8 MiB，请求超时为 15 秒。不支持或无法获取的响应保留原始标题链接。

独立成段的 Google 来源图标链接，如果地址为 `https://www.google.com/s2/favicons` 或 `https://google.com/s2/favicons`，且带有有效的 `domain` 或 `domain_url` 参数，会显示为 16 像素的网站图标链接。紧随其后的简短纯文本站点名（最多 100 个字符，可带加粗或强调）会同行显示；标题、多行正文、以句末标点结尾的句子及其他链接继续分开排版。图标沿用同一套有限的宿主缓存和懒加载流程。获取或解码失败时，原始链接文字仍与站点名一起保留。存储的 Markdown 原文保持不变，来源图标不计入整条标注或章节的图片数量。

普通 Markdown 图片和可识别的图片链接预览，会在 PDF 或 EPUB 文内标注图标旁及侧栏标题中显示 **IMG** 标签。仅含 SVG 时显示 **SVG**，两类都有时使用一个 **IMG · SVG** 组合标签。在文内或侧栏标签上短暂停留，可分别查看总数，例如“本条批注含 2 张图片、1 个 SVG 图”。提示跟随 Zotero 的界面语言，支持中文和英文，其他语言回退到英文。标签和提示层都保持鼠标穿透，页内弹窗不重复添加标签；鼠标移开、滚动、按键或窗口失焦时关闭提示。

数量表示渲染内容中的图片项。尚未加载或加载失败的图片链接仍计数，发现标签不会额外下载图片。SVG 仅统计经过验证的预览，源码示例和被拒绝的图示不计数。关闭 SVG 渲染后，普通图片标签仍然可用。编辑后数量随之更新，大纲标签显示各章节自己的数量。

### SVG 示意图（实验性）

在设置中开启 **渲染 SVG 图示（实验性）**，即可预览静态 SVG 图。默认关闭；开启侧栏或页内弹窗 Markdown 渲染后可用。切换会刷新已打开的 Reader。Zotero 仍保存原始 Markdown 和 SVG 文本，不会创建附件，也不依赖外部图片服务。

SVG 图示也使用上面的图片标签。侧栏评论展开后，标签仍保留在标题中；删除或关闭 SVG 预览时，标签会根据剩余图片内容更新。

复制 AI 的整段回复时，图示可能位于没有语言标记的代码块中。只要整个代码块是一份完整 SVG 文档，也会自动识别；可包含外围空白、XML 声明和注释。仍由同一个 SVG 开关控制，并遵守相同限制。普通代码、不完整片段，以及明确标记为 `xml`、`html`、`text` 等其他语言的代码块继续显示源码。想展示 SVG 源码时，可使用这些语言标记。

从 v0.14.2 起，也支持整条评论仅包含完整裸 SVG，或在 Markdown 段落之间独立占一行或多行的完整裸 SVG。代码围栏和空行分隔均可省略，也支持连续的多份独立 SVG。暂不支持行内、列表、引用或 HTML 容器中的 SVG。仍使用同一个 SVG 开关、验证流程和图片查看器；渲染时的临时边界不会给保存的源码添加围栏。不完整片段保持文本，也不会吞掉后续 Markdown。

~~~~markdown
```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 320 100">
  <rect x="10" y="10" width="300" height="80" rx="8" fill="#eff6ff"/>
  <text x="160" y="56" text-anchor="middle" font-size="18" fill="#1e293b">示意图</text>
</svg>
```
~~~~

图片适配预览宽度。点击 SVG 图片或 **View larger**，可在浮层中查看同一张清洗后的图片，打开时先适配可用空间。SVG 图片显示放大镜光标；保留 **View larger** 供键盘操作，关闭浮层后焦点回到该按钮。可用 **− / +** 调整大小，控制栏会显示当前比例；图像区域内也支持滚轮缩放。图片和浮层一起放大或缩小，浮层保留容纳控制栏的最小空间，按钮和文字大小不变。浮层达到 Reader 边界后停止扩大，更大的图片可通过指针中心滚轮缩放、拖动平移或滚动条查看。**Fit** 是唯一的恢复按钮：图像放得下时恢复原始大小，放不下时缩小到能在 Reader 内完整显示。缩放范围为 1%–400%；较大图示还受每边最多 8192 像素的显示尺寸限制。可通过 **Close**、Escape 或点击遮罩关闭，Tab 和 Shift+Tab 保持在浮层内。点击 SVG 图片外的文字或预览空白区域仍可编辑源码；其他 Markdown 图片沿用现有源码编辑流程。

支持基本图形、路径（包括紧凑坐标写法）、分组、文字/tspan、局部箭头标记、局部线性/径向渐变及受限的内嵌 WOFF2 字体。请用 `fill`、`stroke`、`font-size` 等属性，或下面说明的简单元素/类规则设置外观。文字/tspan 还可使用 `style="white-space: pre;"`，并支持 `direction="ltr"` 或 `direction="rtl"`。暂不支持一般内联样式、嵌入 HTML、外部资源、`use`、动画、滤镜、非空遮罩、文档声明和其他命名空间。SVG 标签中的文字按字面显示；LaTeX 仅在外围 Markdown 中渲染。图中文字不能像 Markdown 文本一样直接选择。

根 `<svg>` 可使用 `role="img"`、`aria-label`、`aria-labelledby` 和 `aria-describedby`。引用列表最多包含 16 个简单 ID，且目标须存在于同一 SVG 中；URL 和缺失目标会被拒绝。预览把其中的纯文本传递到 HTML 图片的替代文本（`alt`）和描述工具提示（`title`），大图查看器也保留两者。名称优先使用 `aria-labelledby`，其次是 `aria-label` 和 SVG 标题；描述优先使用 `aria-describedby`，其次是 SVG 描述。直接标签和解析后的图片文本限制为 1,024 个字符，原有 SVG 标题回退仍限制为 160 个字符。这些根属性经校验后只从图片副本中移除。其他角色、子元素上的无障碍属性和交互式 ARIA 状态暂不属于静态图片支持范围。

`<style>` 中可使用 `text`、`rect` 等简单 SVG 元素选择器、`.node` 等类选择器，或 `text, .label` 等逗号分组。元素名称复用已有 SVG 元素白名单，并区分大小写。规则可设置已支持的填充、描边、透明度、字体、文字对齐和局部箭头属性；矩形规则还可设置圆角几何属性 `rx` 和 `ry`。例如 `text { font-family: sans-serif; }` 可统一设置文字字体，`.node { fill: #fff; stroke: #334155; rx: 16; ry: 16; }` 可应用到 `<rect class="node" .../>`。类选择器优先于元素选择器，同级后面的声明覆盖前面的声明；两者都优先于同一元素的表现属性。混合分组采用实际匹配选择器中的最高优先级，保留正常的 SVG 继承。类名使用 ASCII 字母、数字、`_` 和 `-`，以字母或 `_` 开头，长度不超过 64 个字符；支持注释。规则仅在预览副本中展开为属性，并从图片样式表中移除，保存的 SVG 保持原样。不支持 ID、通配符、命名空间、复合或后代选择器、伪类、CSS 变量、`!important`、转义、一般 at-rule 和未支持的属性。元素规则与类规则共用最多 256 条规则、1,024 条声明的上限，每组最多 16 个选择器，每个元素最多 16 个类名。

受支持的元素/类规则还可使用受限的 `font` 简写，例如 `.title { font: bold 24px "Microsoft YaHei", sans-serif; }`。字号须为使用 `px`、`pt`、`em` 或 `%` 的非负数值（也支持不带单位的零），后接带引号或简单名称组成的字体族列表。字号前可选最多两个字形/字重值，顺序不限：字形支持 `normal`、`italic`、`oblique`；字重支持 `normal`、`bold`、`bolder`、`lighter` 或以 100 为步长的 `100`–`900`。预览把每条简写展开为四个经过校验的属性；省略的字形和字重重置为 `normal`，并遵循声明顺序。展开后的四条属性计入 1,024 条声明上限。行高语法、字体变体/拉伸、系统字体简写、CSS 全局关键字及函数暂不支持，仍回退为原始源码。

对基本的 AI 和绘图工具导出，预览可以忽略根元素的 `version` 属性、仅含 `max-width:100%` 的根元素样式、空元数据/样式表，以及未被引用的空遮罩。复制产生的不换行空格只在标签语法中规范化，文字和引号内的属性值保持原样。这些调整只作用于预览，不改动保存的源码。这属于有限的导出兼容，并不代表支持所有 Excalidraw 导出。

内嵌字体要求使用 `@font-face`、简单的 `font-family` 和单个 `src: url(data:font/woff2;base64,...)`；可选 `format("woff2")`、基本 `font-weight` 和 `font-style` 声明。字体规则可与支持的元素/类规则共存于同一张样式表。每张 SVG 最多 4 个字体，单个解码后的字体数据不超过 8 KiB，合计不超过 16 KiB。仅支持不带附加元数据/私有数据块的单字体 WOFF2 文件。字体只保留在 SVG 图片内部，不会安装或注册到 Reader。不支持的声明或超出限制的字体会说明原因并显示原始源码。

渲染分为三种结果：完整预览、持续显示提示的兼容预览、带原因的原始源码回退。兼容路径只可省略表现属性或受支持元素/类规则中的 `text-rendering`、`shape-rendering` 和 `cursor`，且值必须是单个简单关键字。提示列出省略的属性及总次数，**View larger（放大查看）** 保留相同提示；文字或边缘外观可能发生变化。不会静默移除任意属性或绘图元素；提示项中的函数、URL 和 `!important` 仍被拒绝。所有原始声明，包括未使用、被覆盖及被省略的声明，都须检查并计入原有上限。不支持的几何、变换、字体、引用、会影响图意的样式、格式错误的 CSS 及危险内容，继续回退到源码。

每份 SVG 限制为 32,000 个源码字符、512 个元素、32 层嵌套，图片及 viewBox 尺寸不超过 4096 × 4096。需要 viewBox 或数值形式的宽高。未通过校验时显示简短原因和转义后的代码块；图片加载失败也会显示原始源码，并隐藏兼容提示。向 AI 请求图示时，可要求：输出到 `svg` 代码块或独立完整 SVG，包含 viewBox，使用基本图形与文字，通过属性或简单元素/类规则设置样式，不引用外部资源。

可使用[六个围栏 SVG 样例](../examples/svg-samples.md)或[六个裸 SVG 样例](../examples/svg-raw-samples.md)，其中包括 issue #3 的五个示例。两份指南都提供可直接复制的批注评论、预期结果和人工测试清单。

### 高亮颜色

使用 `==文字==` 显示默认黄色高亮。在结束的 `==` 后面紧接一个受支持的颜色后缀，即可选择其他预设颜色：

```markdown
==默认黄色==
==风险提示=={.red}
==重点内容=={.orange}
==确认结论=={.green}
==补充信息=={.blue}
==个人观点=={.purple}
==次要内容=={.gray}
```

支持的后缀为 `.yellow`、`.red`、`.orange`、`.green`、`.blue`、`.purple` 和 `.gray`。任意类名、多个类名、样式属性和自定义颜色值都不会被解释；未知或未紧接高亮的后缀会作为普通文字保留。

## 安装

推荐在 Zotero 插件市场中搜索 `Zotero Annotation Markdown` 并安装。

也可以从[最新 GitHub Release](https://github.com/qrkks/zotero-annotation-markdown/releases/latest)下载 `zotero-annotation-markdown.xpi`。在 Zotero 中打开 **工具 → 插件**，然后把 `.xpi` 文件拖入插件窗口。

## 设置

打开 Zotero 设置并选择 **Annotation Markdown** 面板。面板跟随 Zotero 的界面语言，目前支持英文和简体中文。如希望新增语言或改进文案，参见[翻译贡献指南](localization.md)。

当前设置包括：

- 是否渲染侧边栏标注评论中的 Markdown；
- 是否在页内标注弹窗中渲染 Markdown；默认关闭；
- 是否把剪贴板内容以纯文本形式粘贴到评论中；推荐在粘贴 AI 回复时启用，使 Markdown 保持可编辑，并避免带入富文本格式或隐藏 HTML；
- 是否使用快速评论编辑器；该功能默认开启，也可以关闭并恢复 Zotero 原生编辑器；
- 是否渲染 LaTeX 数学公式；
- 选择公式渲染方式：默认使用标准渲染，也可选择原生 MathML；
- 是否为包含多个标题的标注显示浮动大纲；该功能默认开启；
- 是否为符合条件的大纲标题组补充层级序号；该选项默认关闭；
- 是否通过下一级智能选项避让已有标题序号；显示标题序号时默认启用；
- 单独将浮动大纲文字大小调整为 80% 到 200%；100% 保持原有大小；
- 是否在标注评论出现 `todo:`、`todo：`、`t:` 或 `t：` 指令时自动给该标注添加 `todo` 标签；默认关闭；
- 是否在移除指令并保存评论后自动清理该标注的小写 `todo` 标签；默认关闭，须先开启自动添加；
- 把预览字号调整为 80% 到 200%；
- 选择标注渲染策略；
- 是否实验性加速超大标注列表取消标签筛选后的恢复；默认关闭。

**阅读器批注** 分组中的 **公式渲染方式** 提供 **KaTeX HTML + MathML（默认）** 和 **仅使用原生 MathML** 两种模式。默认模式由 KaTeX HTML 负责公式的可视排版，并附带供辅助阅读使用的 MathML。原生 MathML 可以降低公式较多的标注的渲染开销，使用 Zotero 原生数学排版，因此公式间距、高度和字体外观可能有所不同。该选项已在 Windows 上的 Zotero 10.0.5 和 10.0.6 中验证。切换后会立即刷新已打开的 Reader，并保留保存的 LaTeX 源码；随时选择 **KaTeX HTML + MathML（默认）** 即可切回。公式渲染是 Markdown 预览的一部分。侧栏和弹窗渲染都关闭时，公式开关与输出方式选择框会置灰，但保留已有选择。重新开启任一渲染后，公式开关恢复可用；输出方式选择框还需要开启公式渲染。

渲染策略包括：

- **自动（推荐）：** 较小的标注集合会提前渲染，较大的标注集合采用视窗懒加载。
- **渲染全部批注：** 调度所有标注预览进行渲染。
- **渲染可视区域附近的批注：** 标注接近侧栏可见区域时才进行渲染。

**加速超大批注列表清除标签筛选（实验性）** 改为探测 Reader 兼容性，不再要求特定 Zotero 版本。挂钩仍要求 React 18.3.1、所需接口与批注组件结构、可写的组件元数据，以及一致的行组件。请在完整标注列表加载后、选择标签筛选前开启此选项。加速需要至少 100 个未选中原生标注行的精确高度缓存，插件会在列表收窄前记录这些高度。随后取消已选标签时，远处标注可以先恢复为等高占位，并在接近视窗或被选中时创建完整原生行。该功能不会加速 Reader 首次打开；高度数据缺失或 Reader 结构不兼容时会自动沿用 Zotero 原生列表。若安装挂钩后初始化异常，会还原原始组件并清理部分启动的运行时。关闭该选项后，占位行会分成小批次异步恢复为原生行。取消 Zotero 版本限制不代表所有版本都已证实有加速效果。

设置会自动保存。Markdown 预览字号位于 **阅读器批注** 分组中，紧邻渲染选项。如果阅读器没有反映新的设置，可以关闭并重新打开该阅读器，或重启 Zotero。

## 预览与编辑状态

**将侧栏批注评论渲染为 Markdown** 与 **将页面批注弹窗渲染为 Markdown** 是两个平级开关，可以只开其中一项，也可以同时开启或关闭。侧栏渲染默认开启，弹窗渲染默认关闭；两项分别保留已有的勾选状态。预览字号、LaTeX 设置和公式输出方式由两者共用。渲染策略只控制侧栏评论，开启弹窗渲染后弹窗会即时处理。

标注未处于编辑状态时，评论显示为渲染后的预览。默认点击侧栏评论后会使用更快的源码编辑器；失焦或按 Esc 时保存修改。关闭 **使用快速批注评论编辑器** 后会恢复 Zotero 原生侧栏编辑路径。侧栏标注折叠时仍沿用 Zotero 的紧凑显示方式。

开启 **将页面批注弹窗渲染为 Markdown** 后，页内标注弹窗会把评论渲染为 Markdown。该选项由独立开关控制，默认关闭。关闭时，弹窗的尺寸、定位、显示和预览渲染保持原生行为。快速编辑由 **使用快速批注评论编辑器** 独立控制：新打开的空弹窗会在 Zotero 布局稳定后直接进入快速文本框，已有弹窗内容则在点击后按需进入。文本框会在失焦或按 Esc 时只保存一次；关闭快速编辑或缺少 Reader 更新能力时，保留 Zotero 原生弹窗编辑器。开启 Markdown 弹窗渲染后，弹窗采用稳定的较宽宽度，并在较窄的 Reader 窗口中自动收缩；预览增加了舒适的内边距。长评论会在受视口限制的区域内纵向滚动，不会被裁掉，拖动或点击滚动条也会保持预览状态。当前批注的预览完成渲染并且布局稳定之前，弹窗保持透明。首次打开和切换批注时，弹窗都会等待新内容完成渲染，再按当前标注位置和最终尺寸定位，避免长公式渲染后再次跳动。空评论自动进入快速编辑器时，也会等文本框尺寸稳定后再显示。

如果当前 Zotero 版本没有提供快速编辑器所需的阅读器标注更新能力，插件会自动让 Zotero 原生编辑器继续接管。

插件不会用生成的 HTML 替换 Zotero 保存的 Markdown 源码。

启用自动 `todo` 标签后，标注评论中只要有一行以 `todo:`、`todo：`、`t:` 或 `t：` 开头（可缩进，不区分大小写，如 `TODO:`、`T：`），新建标注或修改评论并保存时就会给该标注添加小写 `todo` 标签。`t:` 是 `todo:` 的简写，也遵循相同的自动清理规则。已有 `todo` 标签（无论大小写）不会重复添加。该规则不扫描历史标注。

上述两个开关位于设置面板的 **批注标签** 分组。可另外开启自动清理：修改并保存评论时，如果原评论有上述指令、新评论没有，就移除该标注的小写 `todo` 标签。只修改标签或编辑从未含有指令的评论不触发清理。Zotero 无法从同名标签判断是否由插件添加；此选项也可能清理手工添加的小写 `todo`，但不会清理大写 `TODO`。两个开关默认都关闭。

## 浮动大纲

当前选中的标注包含至少两个 Markdown 标题时，一个紧凑的**大纲**按钮会固定在标注侧栏视口旁边，所以长标注开头滚出视野后仍能使用。它优先放在侧栏滚动条右侧的空白区域；窗口较窄时则移到内侧并向左展开。大纲收录 `H1` 至 `H6`，保留标题层级，并高亮标注侧栏顶部附近的当前章节。点击条目只会在标注侧栏内平滑滚动到对应标题，不会进入评论编辑或改变当前选中的标注。

含图片的章节会在大纲标题末尾显示小型 `IMG`、`SVG` 或 `IMG · SVG` 组合标签，悬停在标签或条目上可分别查看普通图片和 SVG 的数量。每张图只归到它前面最近的标题，父级标题不连带显示标签，第一个标题前的图不归入任何章节。尚未加载或加载失败的图片链接仍计数，代码示例以及回退为代码的 SVG 不计入数量。侧栏和页内标注弹窗中的标签都会随预览内容更新；点击标签仍跳转到章节标题。长标题会在标签前截断，保证标签可见；Markdown 源码和正文标题保持原样。

大纲控件和图片数量提示跟随 Zotero 的界面语言，内置中文和英文，其他语言回退到英文。标签上的 `IMG` 和 `SVG` 为通用缩写。

浮动大纲默认启用，可在 **悬浮大纲** 设置分组中通过 **为包含多个标题的批注显示悬浮大纲** 关闭。**大纲字号** 可在 80% 到 200% 之间调整，100% 保持原有大小；它与 Markdown 预览字号独立，调整后会立即更新已打开的 Reader。文字放大时，空间允许的情况下大纲面板也会相应变宽。新安装默认收起大纲；用户主动展开或收起后，该状态会独立保留在不同标注、Reader 标签页及 Zotero 重启之间，因此关闭功能再重新开启也不会覆盖原有选择。少于两个标题的标注不显示大纲；进入评论编辑时只是暂时隐藏，渲染预览恢复后继续采用之前记住的状态。

子选项 **显示标题序号** 默认关闭。开启后，侧栏和页内标注弹窗中符合条件的标题组会添加 `1`、`1.1`、`1.1.1` 等序号。每条标注重新编号，以其中最浅的标题级别为起点，整条标注中出现的各标题级别分别采用固定的编号深度；始终未出现的级别会跳过。缺少父标题时，为父级预留第一个计数，不额外生成大纲条目或零：例如，第一个 `H1` 前符合补号条件且未编号的 `H2` 标题编号为 `1.1`、`1.2` 等，随后第一个 `H1` 编为 `2`。调整后会立即更新已打开的 Reader，且只给大纲添加前缀，保留 Markdown 源码、正文标题和公式。关闭大纲时，该选项会置灰，但保留已保存的选择；编号偏好与大纲展开/收起偏好相互独立。

下一级子选项 **智能避让已有序号** 默认开启。关闭后，所有大纲标题统一补充结构序号，包括原本带手写序号的标题：例如，`五、结果` 可能显示为 `6 五、结果`。两种模式均保留手写原文。关闭标题序号或大纲时，智能选项置灰并保留已保存的选择；切换后立即更新已打开的 Reader。

开启智能选项时，标题开头已有 `一、`、`（一）`、`第一章`、`1. `、`1、`、`(1)`、`1.2. ` 等明确序号会保留手写编号；也支持全角形式以及加粗文字或链接中的序号。同一父级下相邻的同级标题以 `1 标题`、`2 标题` 开始时，也视为已有连续编号；中间可以穿插下级标题，但不跨父级，也不跨过没有编号的同级标题。同一兄弟组中出现明确序号或符合上述条件的连续编号时，该组所有兄弟标题及其全部子孙都保留原始标题，不再添加自动前缀，包括排在它前面的兄弟标题。分组沿用现有大纲层级，以共同父级为边界，不影响其他章节；最高层标题已有序号时，整条标注都停止自动补号。例如，`第三章 结果` 及其所有兄弟和子孙均保留原文，避免手写章节号与自动子标题号不匹配。标题仍占据原有结构位置，不采用手写序号的数值重设计数。孤立的 `1 标题`、未从 `1` 开始或不连续的数字、`01` 等带前导零的数字、`1.2 参数` 等小数前缀、日期、开头的公式和代码示例仍不会单独触发组退让；所在分支允许自动编号时，它们仍会补号。

## 侧栏定位

从侧栏或文档页面选择标注时，使用 Zotero 原生平滑滚动。单条选中标注高于侧栏视口时，无论向前还是向后切换，都会把开头定位到顶部附近，保留 2px 间距。短标注沿用原生定位。手动滚动不会自动回到选中的标注。

按 **Esc** 会保存并退出快速编辑。预览恢复后，只要标注还有一部分可见，就保持当前位置，不回到开头；只有整条标注都在视口外时，才在侧栏可滚动范围内平滑滚动一次，定位到同样的顶部 2px 位置。新的滚动、点击、输入、焦点变化或切换选中标注会取消待执行的定位补救。

点击其他位置也会保存，但普通失焦不会把上一条标注拉回视窗，方便继续操作另一条标注、文档页面或其他控件。

## 为什么替代编辑器可以更快

在真实阅读器的对比中，一本重度标注书籍的侧栏积累大量标注行和标签后，编辑会逐渐变慢。关闭替代编辑器会重新出现明显延迟，开启后输入又恢复流畅。这说明该工作负载下的主要延迟位于 Zotero 原生编辑路径，但不能据此断言只有标签数量是原因，也不能把问题归结到某一个尚未确认的 Zotero 内部函数。

Zotero 原生评论编辑器需要参与宿主管理的选中状态、焦点、编辑器组件状态和侧栏布局。周围侧栏越大、结构越复杂，这些工作就越可能变得昂贵。本插件避免让每次按键都进入这套原生编辑 UI：

1. 只为当前评论挂载一个轻量文本框，并保持周围标注预览连接不变。
2. 输入期间暂停插件自己的 Markdown 渲染工作，并把编辑器键盘事件限制在文本框内。
3. 失焦或按 Escape 时，通过 Zotero 的标注管理器一次性提交最终 Markdown 源码。
4. 保存后只刷新刚刚编辑的评论，并尽量保持侧栏中的可见位置。

插件不会建立另一套评论数据库，也不会绕过 Zotero 保存标注的数据模型。缺少必要的保存能力或用户关闭该偏好设置时，仍由 Zotero 原生编辑器接管。

## 兼容性

当前实现声明支持 Zotero Desktop 9.0 和 10.0.x。本版优先验证最新版 Zotero 10；Zotero 9 按尽力兼容原则保留支持，快速编辑集成不可用时可以回退原生编辑器。

阅读器侧栏 DOM 不是完全稳定的公开 API。即使自动化测试通过，Zotero 更新后仍应重新进行真实环境验证。
