## Representative rendering cost / 代表性渲染耗时

In the actual Zotero runtime, a warmed renderer's median of seven runs for the Jordan diagram with surrounding formulas was **13.50 ms raw** versus **12.74 ms fenced**; ordinary Markdown without SVG was **0.53 ms**. This measures one small input and excludes viewer layout, initial startup and large annotation collections; it is not a general performance guarantee.

在真实 Zotero 运行环境中，预热后对带外围公式的 Jordan 图示渲染七次，耗时中位数为 **裸 SVG 13.50 ms**、**围栏 SVG 12.74 ms**；不含 SVG 的普通 Markdown 为 **0.53 ms**。此结果仅代表一个小样例，不包含查看器布局、首次启动或大量批注，不作为一般性能保证。
