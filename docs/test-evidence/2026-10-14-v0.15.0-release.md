# v0.15.0 release validation / v0.15.0 发布验证

Date / 日期: 2026-10-14

## English

The release excludes document-opening acceleration. Its complete implementation
is preserved on `qrkks/reader-startup-experiment`, commit `7b74352ca2fc7d2b093bf16d6a2b238f5a5cda3b`.
Main keeps the development-only probes and historical test records. The packaged
add-on has no startup/session/tab-load hook or opening-acceleration preference.

The candidate XPI is 1180926 bytes, SHA-256 `8a549a1cccf5cf161b36a3c742542735d6fc1920751da2f0a93db48108c5bf68`.
Full verification passed **36 test files / 952 tests**, strict type checking,
five bilingual documentation pairs, build and package, release-metadata checks
and the production-dependency audit (no known vulnerabilities).

The exact package was installed in a dedicated Zotero 10.0.6 / Gecko 140 profile,
then tested after a full process restart. Three SVG fixtures (Jordan, EFA class
styles and EFA font shorthand) passed **27 checks**: persistent omission warnings,
zero pixel differences from supported reference images, viewer warning/close/focus,
live SVG preference refresh, image-error source fallback, editing/saving complete
and unsafe SVG, rendering disable cleanup and re-enable. Original comments were
restored and compared with the pre-test copies in both the small and large test
documents. The daily library was not edited.

Initial hot-session preparation/focus races are retained privately as failed
probe attempts, not included in the passed count. The successful probe also waits
for the native editable DOM to reflect persisted fixture input before rendering.
This evidence does not claim universal tag-filter speed or document-open gains.
SVG and tag-filter acceleration remain experimental and disabled by default;
native MathML loses only its experimental label.

## 简体中文

本次发布不包含文件打开加速。完整实现保留在 `qrkks/reader-startup-experiment`
分支，提交为 `7b74352ca2fc7d2b093bf16d6a2b238f5a5cda3b`；主线保留仅供开发使用的探针和历史
测试记录。发布包没有启动/会话/标签加载挂钩，也没有文件打开加速设置。

候选 XPI 大小为 1180926 字节，SHA-256 为 `8a549a1cccf5cf161b36a3c742542735d6fc1920751da2f0a93db48108c5bf68`。
完整验证通过 **36 个测试文件、952 项测试**、严格类型检查、五组双语文档检查、
构建、打包、发布元数据检查及生产依赖审计，未发现已知漏洞。

将准确的发布包安装到独立的 Zotero 10.0.6 / Gecko 140 测试配置，完整重启后，
Jordan、EFA 类样式及 EFA 字体简写三组 SVG 共通过 **27 项检查**：持续省略提示、
与支持的参考图片零像素差异、大图提示/关闭/焦点、SVG 开关刷新、图片加载失败
的源码回退、完整及危险 SVG 的编辑保存、关闭渲染清理及重新启用。原始评论全部
还原，并与大小两份测试文档的测试前副本逐项比较；日常文库未被编辑。

最初热环境的测试准备和焦点竞争作为失败探针记录私下保留，不计入通过项。成功
探针还会等待原生编辑 DOM 显示已经保存的测试内容，再开启预览。本记录不声称
所有宿主的标签筛选速度或文档打开速度都得到改善。SVG 与标签筛选加速继续保留
实验性标签、默认关闭；原生 MathML 只移除实验性标签。

上面的结构化证据和暂缓发布决定链接提供完整记录。
